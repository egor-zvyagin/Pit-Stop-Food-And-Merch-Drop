# Pit Stop frontend

Next.js 14 (App Router) application: the fan web app, the vendor terminal and the API routes.

Project overview, architecture, setup and testing are documented in the [repository README](../README.md). Deployment is covered in the [deployment guide](../DEPLOYMENT_GUIDE.md).

Quick start:

```bash
npm ci
cp .env.example .env.local   # then set VENDOR_ACCESS_PIN
npm run dev
```
